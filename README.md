# 👋 Hola, soy Fermín Gonzalez

**Entusiasta de DevSecOps, cloud y agentes de IA.** Me interesa construir y asegurar infraestructura como código, observabilidad y sistemas que trabajan por ti — desde pipelines seguros hasta agentes que te resumen las noticias cada mañana.

## 🧑‍💻 Sobre mí

Profesional de TI enfocado en el mundo cloud y la automatización. Disfruto tocando distintas capas del stack: desde scripts en Bash y Python hasta infraestructura en Azure con Terraform, pasando por observabilidad con Dynatrace y análisis de seguridad con KQL. Actualmente explorando cómo los agentes de IA pueden asistir en operaciones, investigación y desarrollo.
